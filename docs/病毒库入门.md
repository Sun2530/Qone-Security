# 病毒库入门：从一次手工排查到一条能用十年的规则

> 写给人看的，不是给编译器看的。作者：Sun2530
> 适用项目：Qone Security 1.2+

---

## 一、先说清楚"病毒库"到底是什么

这个词被厂商包装得很玄，拆开只有四种东西。认清这四种，就没有神秘感了。

| 形态 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| 哈希库 | 整个文件的指纹，一个字节不同就不命中 | 零误报、极快 | 改一个字节就失效，对变种完全瞎 |
| 字节特征码 | 从样本里截一段固定的字节串 | 能扛小幅修改 | 需要人工逐样本提取，已被淘汰 |
| YARA 规则 | 字符串 + 逻辑判断，描述"长相" | 能扛变种、可读可审计 | 写不好会大面积误报 |
| 启发式打分 | 多个可疑点累加计分 | 能抓没见过的新东西 | 必然有误报，需要调权重 |

**现代做法是后两种为主，哈希库做兜底黑名单。** 本项目四层都实现了，顺序是：

```
哈希库（秒杀已知） → YARA（认长相） → PE 启发式（看结构） → clamd（可选，用户的库）
```

前一层命中就短路，不再往下走。所以哈希库再大也快 —— 它是 O(1) 查表。

## 二、你其实已经会的部分

在贴吧给人清木马，你干的事情是：

1. 看这机器上多了什么进程、什么服务、什么启动项
2. 看这些文件从哪来、像不像正经软件
3. 判断"这是银狐还是普通流氓软件"
4. 删掉、修复、告诉用户下次别点

第 3 步就是**规则匹配**。第 2 步就是**特征提取**。你缺的只有"把它写下来"这一步。

所以不要从"学病毒库理论"开始 —— 没有这种理论。直接从**把你上一次判断的过程写成十行代码**开始。

## 三、五步法

### 01 收样本

**合法渠道，按优先级：**

| 渠道 | 说明 |
|---|---|
| 自己做诱捕 | 蜜罐、贴吧私信收到的可疑附件、朋友中招后要来的文件 |
| abuse.ch MalwareBazaar | 免费 Auth-Key，官方 API 下载，注意它**不是 CC0**，只能自用不能转存分发 |
| theZoo / vx-underground | 学术研究用的公开样本集，注意各仓库自己的许可 |
| 自己造 | 写个只弹窗不干坏事的模拟样本，用来验证检测链路（EICAR 就是这个思路） |

**红线：**

- 绝不把样本或样本摘要打包进你分发的安装包（除非许可明确允许）
- 绝不在宿主机上双击运行。用 Windows 沙盒 / 虚拟机，分析完直接丢弃
- 沙盒跑之前先在 BIOS 开 VT-x，否则 Windows 沙盒起不来

**你最大的优势在这里**：你是「电脑病毒与问题解决吧」创始人，天天有人拿样本求鉴定。这条管道别人求都求不到。

### 02 静态拆开

不运行，只看文件。要看的就五样：

| 看什么 | 用什么 | 找什么 |
|---|---|---|
| 哈希 | `Get-FileHash`、`certutil -hashfile x SHA256` | 先扔 VirusTotal 看有没有人见过 |
| 字符串 | Sysinternals `strings.exe`，或 FLOSS（解混淆） | URL、IP、路径、互斥体、报错文案 |
| 导入表 | PE-bear / CFF Explorer / 本项目 `peheur.py` | 进程注入、提权、网络、加密相关 API |
| 节区 | 同上 | 异常节名、体积比例失衡、熵接近 8.0 |
| 资源/附加数据 | PE-bear | 尾部藏着的第二个 PE（白加黑常见） |

一条命令把所有可打印字符串捞出来存盘，方便 grep：

```powershell
strings.exe -n 6 -nobanner suspect.exe > s.txt
```

### 03 挑信号（最关键的一步）

新手死在这里：把 `GetProcAddress` 写进规则，一扫全盘几千个文件报警。

**信号分三档：**

**强信号** —— 只属于这个家族，出现一个就能定性

- 互斥体名（`Global\xxxx`，程序用它防止自己开两份，名字往往是家族代号）
- C2 域名、URI 路径
- 独有的报错/提示文案（中文木马常有"配置加载失败"之类的话）
- 硬编码的加密密钥、盐值
- 遗留的 PDB 路径（`C:\Users\张三\Desktop\银狐\loader\p.cbproj`，直接暴露作者）
- 特定的注册表路径组合

**中信号** —— 组合后才成立

- 特定 API 组合（如 `OpenProcess` + `VirtualAllocEx` + `WriteProcessMemory` + `CreateRemoteThread`）
- 异常节区名（`.abc`、随机字母）
- 编译时间戳晚于文件修改时间，或为 1970/2038 附近
- 导入表项极少（加壳典型特征）
- 引用不存在的 DLL 导出函数（侧加载常用）

**弱信号** —— 只能加分，永不定性

- `GetProcAddress`、`LoadLibrary`、`VirtualAlloc`、`CreateThread`
- Base64 字母表
- `cmd.exe`、`powershell.exe` 字样
- 高熵（很多正常程序也是压缩过的）

**判定公式：**

```
一条强信号           → 命中
两条以上中信号       → 命中
强 + 中              → 命中
只有弱信号           → 不命中，最多给启发式加 5 分
```

### 04 写成规则

最小可用模板，直接改：

```yara
import "pe"

rule FamilyName_Loader
{
    meta:
        description = "一句话说清它是什么、干什么"
        author      = "Sun2530"
        license     = "MIT"
        severity    = "high"          // high / medium / low
        family      = "downloader"    // 身份标签，见下表
        reference   = ""              // 样本来源，可留空
    strings:
        $m1 = "Global\\SomeMutex" ascii wide     // 强：互斥体
        $c1 = "/api/gate.php"     ascii nocase   // 强：C2 路径
        $p1 = { 6A 00 6A 00 E8 }                 // 中：字节序列
        $s1 = "SeDebugPrivilege"  ascii          // 弱：API 名
    condition:
        uint16(0) == 0x5A4D and      // 必须是 PE
        filesize < 12MB and          // 大小窗口
        not pe.is_signed and         // 无签名
        (
            any of ($m1, $c1) or
            2 of ($p1, $s1)
        )
}
```

**只需要记住这些语法：**

| 写法 | 含义 |
|---|---|
| `"文本" ascii` | 按 ASCII 找 |
| `"文本" wide` | 按 UTF-16 找（Windows 程序大量用这个，中文尤其） |
| `"文本" nocase` | 忽略大小写 |
| `{ 4D 5A ?? 00 }` | 十六进制字节，`??` 是通配 |
| `$a and $b` | 两个都要有 |
| `$a or $b` | 有一个就行 |
| `any of ($a, $b)` | 列表里任意一个 |
| `all of them` | 所有字符串都要有 |
| `2 of ($a, $b, $c)` | 至少两个 |
| `#a > 3` | 字符串 a 出现超过 3 次 |
| `$a at 0` | 出现在文件开头 |
| `filesize < 1MB` | 大小限制 |
| `uint16(0) == 0x5A4D` | 开头是 MZ，即 PE 文件 |

条件里能用 `and or not` 和括号，跟写 Python 一样。

**`family` 决定结果页那个身份标签。** 不写也能跑——程序会按规则名和描述去猜，
但猜出来的往往是「可疑文件」。写了就是你自己认定，用户看到的也就具体：

| family | 界面显示 | 什么情况用 |
|---|---|---|
| `silverfox` | 银狐木马 | 银狐家族（ValleyRAT / Winos 一类），国内高发 |
| `ransom` | 勒索软件 | 加密文件、勒索信、索要赎金 |
| `stealer` | 窃密木马 | 偷浏览器密码、cookie、聊天记录 |
| `backdoor` | 后门程序 | 远程注入、隐蔽通道、留后路 |
| `spyware` | 间谍软件 | 键盘记录、截屏、监视 |
| `rat` | 远控木马 | 通用远程控制家族 |
| `downloader` | 下载器 | 下载执行、加载器、白加黑侧加载 |
| `miner` | 挖矿程序 | 占用算力、矿池连接 |
| `adware` | 广告软件 | 弹窗、劫持主页 |
| `script` | 恶意脚本 | PowerShell / VBS / JS 一类 |
| `trojan` | 木马程序 | 是木马但说不清具体类型 |
| `pup` | 风险软件 | 捆绑安装、推广 |
| `test` | 测试样本 | EICAR 这类无害的链路测试文件 |
| `unknown` | 可疑文件 | 认不出类型，但确实可疑 |

写错或不认识的取值不会导致规则失效，只是退回「可疑文件」。
**宁可标「可疑文件」，也不要为了好看硬套一个家族名**——用户会拿着错名字去搜，
然后被假客服骗，这比不标更糟。

### 05 白测收口

**规则写完不测就上线，等于给自己挖坑。** 本项目那次 `WeChatAppEx.exe` 误报就是这么来的 —— 规则逻辑没错，但没收口。

回测方法：拿规则去扫这几个目录，**任何一个命中都是误报**：

```
C:\Windows\System32
C:\Windows\SysWOW64
C:\Program Files
C:\Program Files (x86)
你自己的用户目录（尤其是微信、QQ、浏览器）
```

正规软件都有数字签名，所以加 `not pe.is_signed` 能挡掉 90% 的误报 —— 这也是为什么这条几乎该写进每条规则。

误报出现了怎么修，按顺序试：

1. 加 `not pe.is_signed` —— 挡掉所有正规软件
2. 加 `filesize` 窗口 —— 挡掉体量完全不同的东西
3. 加 `uint16(0) == 0x5A4D` —— 挡掉脚本和文档
4. 把弱信号从 condition 里删掉
5. 把"任意一条强信号"改成"两条强信号同时出现"

**顺序不要反。** 先收窄，再考虑放弃。

## 四、规则放哪里

两个位置，程序都会加载：

| 位置 | 用途 |
|---|---|
| `assets/yara/qone-core.yar` | 随程序分发的内置规则，改动需要重新打包 |
| `%LOCALAPPDATA%\Qone Security\yara\*.yar` | 用户自己的规则，丢进去重启就生效，不用改程序 |

调试期都放第二个。成熟了再合并进第一个。

写完检查语法：

```powershell
python -c "import yara; yara.compile(filepath='test.yar'); print('OK')"
```

## 五、给你的三个练习，从易到难

**练习一：认得出，写不出**
拿手头任意一个已知木马样本，只用 `strings` 找三个强信号，写进规则的 `strings:` 段，condition 先只写 `any of them`。跑通就行，不追求准。

**练习二：收口**
把练习一的规则去扫 `C:\Windows\System32`，看报几个。每报一个，加一条限定把它压掉，直到零误报。**这个过程比写规则本身重要十倍。**

**练习三：真规则**
选一个你最熟的家族（银狐、某个远控），找你手上三个不同变种的样本，提取它们的**共同**强信号。共同点才是家族特征，单样本特征只能叫单样本特征。

## 六、规模这件事，别硬追

厂商的库有上千万条，那是几百人几十年 + 每天几十万新样本喂出来的。一个人不可能追上，也不应该追。

**个人/小项目的正确策略是"窄而深"：**

- 通用库只留高置信度的几百条，宁漏不错
- 把力气全砸在你熟的领域（国产木马、银狐、远控、白加黑），做到"这个圈子里我比厂商准"
- 用户装 ClamAV 就白得几百万条兜底，这是最划算的一步

一个能精准抓银狐全家族、几乎不误报的十兆小工具，比一个装了一千万条哈希、什么都拦不住的大家伙有价值得多。

## 七、合规红线（给自己划的，别越）

1. **不打包别人的库。** MalwareBazaar 不是 CC0，转存即违约。走官方 API 让用户自己同步，数据在用户机器上，这就不算分发。
2. **不内置活体样本。** 内置的只有 EICAR 这种公开测试文件。
3. **引第三方规则集要逐文件核许可。** 仓库根目录写 MIT，不代表每条规则都是 MIT。
4. **规则文件里写明作者和许可。** 本项目统一 MIT + `author = "Sun2530"`。
